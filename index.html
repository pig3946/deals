순위는 어떻게 정해지나요?

네이버 쇼핑 API 가격과 제조사 공식 스펙만 사용합니다. 광고비를 받거나 순위를 조작하지 않습니다.

왜 '확인 중'이 있나요?

제조사가 공식적으로 공개하지 않은 스펙은 추정하지 않고 '확인 중'으로 표시합니다.

수수료가 순위에 영향을 주나요?

아닙니다. 순위는 가격·스펙 데이터로만 결정됩니다. 수수료는 구매자에게 추가 비용을 발생시키지 않습니다.

표시 가격은 네이버 쇼핑 API 일반 회원 기준이며, 네이버 플러스 멤버십·쿠팡 와우 회원은 추가 할인이 적용될 수 있습니다.
이 페이지의 링크를 통해 구매 시, 운영자에게 소정의 수수료가 지급됩니다(쿠팡파트너스·네이버 쇼핑커넥트). 구매자에게 추가 비용은 없으며, 가격·순위에 영향을 주지 않습니다.
